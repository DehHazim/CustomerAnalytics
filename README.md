# Customer Analytics Data Pipeline

Data pipeline project focused on collecting, transforming, validating, and organizing customer and business metrics data for analytics and reporting.

## What This Project Does

- Extracts data from CSV, JSON, and API-like JSON sources.
- Cleans and transforms customer, order, payment, and campaign data with Pandas.
- Applies data validation and integrity checks before loading.
- Creates dimensional and fact datasets for reporting.
- Loads curated tables into a SQLite analytics warehouse.
- Exports business metrics as CSV files for dashboard or BI consumption.
- Provides SQL queries for revenue, customer, and campaign insights.
- Provides a local browser dashboard for quick visualization.

## Tech Stack

Python, SQL, APIs, Pandas, ETL, JSON, CSV, SQLite, HTML, CSS, JavaScript

## Project Structure

```text

|-- data/

|       |-- extract.py
|       |-- transform.py
|       |-- validate.py
|       |-- load.py
|       `-- pipeline.py
|-- warehouse/            # SQLite database generated by the pipeline

|-- serve_dashboard.py
|-- pyproject.toml
`-- requirements.txt
```

## Quick Start

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the ETL pipeline:

```bash
python main.py
```

Run the local dashboard:

```bash
python serve_dashboard.py
```

Open the URL printed in the terminal, usually:

```text
http://127.0.0.1:8000/dashboard/
```

The pipeline creates:

- `data/processed/*.csv`
- `data/analytics/*.csv`
- `data/analytics/validation_report.json`
- a SQLite warehouse. The default target is `warehouse/customer_analytics.db`; if OneDrive blocks SQLite I/O, the pipeline writes to a temporary `CustomerAnalytics` folder and prints the actual path.

## Example Outputs

The curated warehouse includes:
